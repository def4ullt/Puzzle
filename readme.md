# Числовий пазл

Програма знаходить найдовший ланцюг із шестизначних частинок.
Останні дві цифри попередньої частинки мають збігатися
з першими двома цифрами наступної.

Кожну частинку можна використати лише один раз.

Приклад:
```text
(94)25(17) → (17)07(94) → (94)36(93)
```

## Вхідні дані

Програма читає частинки з файлу `source.txt`, розділені
пробілами або переносами рядків. Кожна частинка має
складатися рівно з шести цифр.

## Алгоритм

Використано рекурсивний перебір із поверненням (backtracking).
Пошук запускається з кожної частинки.

Під час перебору програма позначає використані частинки,
будує поточний ланцюг і зберігає найдовший знайдений.

Для прискорення індекси частинок заздалегідь згруповані
за першими двома цифрами. На кожному кроці розглядаються
лише кандидати, початок яких збігається з кінцем поточної
частинки.

Групування зменшує витрати на пошук кандидатів, але
кількість можливих ланцюгів у найгіршому випадку
залишається факторіальною.

## Збірка та запуск

Для Microsoft Visual C++ виконайте в Developer Command Prompt:

```cmd
cl /EHsc /O2 Puzzle.cpp /Fe:Puzzle.exe
Puzzle.exe
```

Запускати програму потрібно з папки, де лежить `source.txt`.
